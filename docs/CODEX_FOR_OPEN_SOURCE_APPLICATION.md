## Why is this repository eligible?

AI Workstation Router is an actively maintained open-source developer tool that makes AI coding workflows more cost-efficient and resilient by routing tasks across local, lower-cost cloud, and stronger cloud models. It exposes an OpenAI-compatible API, keeps routing transparent, and is designed for Codex/OpenCode-style automation. The project is new, so public adoption is still early, but the problem is broadly relevant to AI developers.

## How will API credits be used?

API credits would be used for maintainer automation, integration tests, compatibility checks, routing benchmarks, release validation, and Codex-assisted issue/PR triage. The goal is to test real OpenAI/Codex workflows while keeping a reproducible local-first fallback path and publishing the resulting integration patterns for other developers.
