# Contributing

Contributions are welcome.

## Development

1. Fork the repository.
2. Create a focused branch.
3. Run:
```bash
npm run check
npm test
```
4. Open a pull request describing the problem, proposed change, and how it was tested.

## Bug reports

Include OS, Node.js version, provider/model, expected behavior, actual behavior, and minimal reproduction steps.

Never include API keys, passwords, tokens, private URLs, SSH keys, or other secrets.
