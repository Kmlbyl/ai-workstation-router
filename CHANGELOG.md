# Changelog

## 0.1.0 - 2026-09-22

### Added

- reusable router under `src/`;
- explicit **Local → GPT-5.6 Luna → GPT-5.6 Sol** economic routing policy;
- direct OpenAI-compatible cloud configuration;
- backward-compatible `cheap` → `luna` and `powerful` → `sol` aliases;
- explicit route overrides;
- bounded fallback routing;
- OpenAI-compatible non-streaming endpoint;
- health/config endpoint;
- in-memory statistics;
- safe environment template;
- tests and CI;
- OpenCode-style integration example;
- contribution, security, architecture, roadmap, release, and OSS-application documentation.

### Notes

The original Windows/OpenCode prototype remains in the repository while the reusable implementation evolves.
