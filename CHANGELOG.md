# Changelog

## 0.1.0 - 2026-09-22

### Added
- reusable router under `src/`;
- local, cheap, and powerful routing tiers;
- explicit route overrides;
- fallback routing;
- OpenAI-compatible non-streaming endpoint;
- health/config endpoint;
- in-memory statistics;
- safe environment template;
- tests and CI;
- contribution, security, architecture, and roadmap documentation.

### Notes
The original Windows/OpenCode prototype remains in the repository while the reusable implementation evolves.
